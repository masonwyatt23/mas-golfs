# Mas Golfs — 60-Day Clip Content Calendar

**The show:** Mas — Mason's digital twin, a left-handed +3 — plays 18-hole rounds on repeat, forever, at Wyatt National (par 72). The season arc is **Road to 59**. The stream never goes dark. This calendar is the day-by-day posting plan for the first 60 days: one clip per day, 1–2 on drama-90+ days, built from the formats in the [launch playbook](launch-playbook.md) and the [creator growth playbook](creator-growth.md).

**Day 1 is a Monday.** Wednesdays are round-premiere days, Fridays are best-of days, Sundays are Road to 59 update days — matching the fixed premiere schedule.

---

## How to use this calendar

### The daily workflow (15 minutes, every evening)

1. Open the daily clip queue, sorted by drama score.
2. Find the moment that matches today's planned format and title. If the exact moment doesn't exist, use the closest moment in the same format — the title is the brief, not a straitjacket.
3. Check the hook: the first frame shows the payoff. If not, re-cut to start 1 second later.
4. Check captions: readable on mute, no typos, decision line correct.
5. Post in today's platform order, same day, within an hour. First comment on each post: the decision line + "Full round live now — link in bio."
6. Log it: clip, platform, format, drama score, link.

| **RC** | Record-chase update | Where Mas stands vs. 59 — only while genuinely on pace, or the morning after a near-miss. |
| **DX** | Day X of Road to 59 | The numbered daily series entry. Same opening line every day, updated numbers. |
| **CC** | The coin call | A Clubhouse Coins prediction before a shot, resolved on camera. |

### The two rules that govern the whole calendar

1. **No format repeats three days in a row.** The rotation is built so every format gets a breather. If a swap is needed, swap within the same week — never let one format run three straight days.
2. **Milestone days are slots, not guarantees.** The stream decides when milestones happen. A milestone day (marked ★) means: *if the milestone happened, post it; if it hasn't, post the fallback clip in the Notes column.* Never manufacture a milestone. The fallback is the plan, not a failure.

### Platform order

- **Default: Reels → Shorts → TikTok.** Instagram is the brand anchor (Mason W Golf); Reels go first.
- **Wednesdays (round premiere): Shorts → Reels → TikTok.** The Short carries the Related Video link to the premiere — it goes first so the bridge is live before the premiere starts.
- **Challenge days (marked ◆): TikTok → Reels → Shorts.** Challenge-framed clips go to TikTok first — challenges are TikTok's highest-median format.
- Never cross-post with a watermark. Clean master per platform, always.
- Every clip carries the same two tags: **#MasGolfs** and **#RoadTo59**.

### Second clips

On days marked **2×**, post a second clip if any moment scored drama 90+. The second clip is always the **Day X of Road to 59** entry — it is the series format, and it stacks on top of anything.
